# Mi Empresa Landing Page

Este proyecto es una página de aterrizaje para "Mi Empresa", desarrollada con HTML5, CSS3 y JavaScript.

## Estructura del Proyecto

El proyecto se ha reestructurado para una mejor organización:

- `index.html`: Archivo principal de la página.
- `css/`: Contiene los archivos de hojas de estilo (`styles.css`).
- `js/`: Contiene los archivos de scripts (`scripts.js`).
- `assets/`: Carpeta para recursos multimedia.
    - `images/`: Imágenes utilizadas en la web.
    - `icons/`: Iconos y favicons.
    - `videos/`: Videos de fondo y promocionales.

## Instalación y Uso

1.  Clona este repositorio o descarga los archivos.
2.  Abre `index.html` en tu navegador web preferido.

## Notas

- Asegúrate de colocar el archivo `video.mp4` en la carpeta `assets/videos/` para que el video de fondo funcione correctamente.

# English Version

# Mi Empresa Landing Page

This project is a landing page for "Mi Empresa", developed with HTML5, CSS3 and JavaScript.

## Project Structure

The project has been restructured for better organization:

- `index.html`: The main page file.
- `css/`: Contains the stylesheet files (`styles.css`).
- `js/`: Contains the script files (`scripts.js`).
- `assets/`: Folder for multimedia resources.
    - `images/`: Images used on the site.
    - `icons/`: Icons and favicons.
    - `videos/`: Background and promotional videos.

## Installation and Usage

1.  Clone this repository or download the files.
2.  Open `index.html` in your favorite web browser.

## Notes

- Make sure to place the `video.mp4` file in the `assets/videos/` folder so the background video works correctly.
